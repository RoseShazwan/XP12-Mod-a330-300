# X-Plane 12 Airbus A330-300 Controller

A touchscreen-based cockpit controller for X-Plane 12, currently designed exclusively for the Airbus A330-300.

## About

This project aims to help X-Plane 12 players who primarily use a keyboard and mouse, especially those who enjoy flying in first-person cockpit mode.

Instead of constantly moving the mouse around the virtual cockpit to locate buttons, switches, and levers, this application provides dedicated control modules for essential aircraft systems.

The main goal is to make flying more convenient, particularly during critical flight phases such as takeoff, approach, and landing. This allows pilots to focus on flying without constantly interacting with the virtual cockpit using a mouse.

## Available Modules

### 1. Aircraft Controllers

Controls for essential aircraft systems and inputs.

- Thrust Levers
  - Supports IDLE, CL, FLX/MCT, and TOGA detents.
  - Includes thrust lever synchronisation with the aircraft.
- Engine Master Switches
  - ENG 1
  - ENG 2
- Flaps
- Spoilers / Speedbrakes
- Parking Brake
- Landing Gear

### 2. Autopilot (FCU)

Controls for the Flight Control Unit.

- SPD (Speed)
  - Push and Pull
- HDG (Heading)
  - Push and Pull
- ALT (Altitude)
  - Push and Pull
- V/S (Vertical Speed)
  - Feet per minute (FPM)
- Guidance and Autopilot Buttons
  - AP1
  - AP2
  - A/THR
  - EXPED
  - APPR
  - LOC

### 3. ATC Transponder

Controls for the aircraft's ATC transponder and TCAS systems.

- Transponder Code Entry
  - Individual digit controls
  - CLR (Clear)
  - IDENT (Identification)
- Quick Squawk Presets
  - 7000 (VFR - Europe)
  - 1200 (VFR - United States)
  - 7600 (Radio Communication Failure)
  - 7700 (General Emergency)
- Transponder Modes
  - STBY
  - AUTO
  - ON
  - ALT
- TCAS Controls
  - Traffic mode and altitude range selection
  - THRT
  - ABV
  - ALL
  - BLW

## Default Configuration

When the application is first loaded, all controls are initialised to their respective cold and dark cockpit configuration.

This provides a consistent starting point for pilots beginning a flight from a cold start.

## Compatibility

- Simulator: X-Plane 12
- Aircraft: Airbus A330-300
- Input Method: Touchscreen
- Other Aircraft: Not currently supported

## Project Goals

The main goal of this project is to make X-Plane 12 more accessible and enjoyable for players who prefer flying in first-person cockpit mode using only a keyboard and mouse.

In first-person mode, interacting with cockpit controls can be cumbersome, as players often need to move the mouse around the cockpit to locate and operate individual buttons, switches, and levers.

This application aims to address that limitation by providing dedicated touchscreen control panels for essential aircraft systems. Players can operate these controls directly from a separate touchscreen device without having to constantly navigate the virtual cockpit.

Ultimately, the goal is to provide a more convenient and immersive flying experience, allowing players to focus on operating the aircraft rather than searching for cockpit controls.
